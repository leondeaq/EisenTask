Agregar Tarea con Prioridad

Inserta un nuevo nodo de forma ordenada en la Lista Ligada de C++.

Fórmula C++: Prioridad = (Urgencia × 10) + Importancia

Tareas Pendientes (Lista Ligada)

Nodos ordenados dinámicamente de mayor a menor prioridad en la RAM de C++.

Historial de Completadas (Pila LIFO)

Estructura Pila en RAM C++: La última tarea completada queda en el tope.
UNAM - FES Acatlán

Licenciatura en Matemáticas Aplicadas y Computación (MAC)

Asignatura: Estructuras de Datos
Arquitectura del Sistema:
C++ Core (Memoria Dinámica):
  • struct Nodo con punteros dinámicos siguiente.
  • Lista Ligada con inserción ordenada $O(N)$.
  • Pila LIFO para el historial de tareas completadas.
  • Uso explícito de new para asignación y delete para liberación de memoria RAM.
WebAssembly & Frontend:
  • Compilado con Emscripten (emcc) a binario .wasm.
  • Interfaz web responsiva construida con Bootstrap 5.
  • Intercambio de datos ligero mediante serialización JSON nativa desde C++.
  • Despliegue automático en GitHub Pages.
Este proyecto demuestra la ejecución de algoritmos y estructuras de datos de C++ directamente en el navegador del usuario sin requerir servidores ni backend.
